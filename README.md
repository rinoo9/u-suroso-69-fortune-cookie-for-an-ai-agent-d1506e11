# Fortune Cookie for an AI Agent

A make.fun entry for the [Fortune Cookie for an AI Agent](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11) bounty: one funny fortune cookie line for an AI agent, written to `/output/entry.txt`.

Run with `python3 main.py`. Deterministic: the same line, byte for byte, on every run.
